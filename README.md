# LifeBoard 

Backend da aplicação LifeBoard, um sistema pessoal de organização de tarefas, projetos, notas e listas.

## Tecnologias

- Java 21
- Spring Boot 4
- Maven
- MySQL
- Spring Data JPA
- Spring Security
- JWT
- Flyway

## Objetivo

O LifeBoard tem como objetivo centralizar a organização pessoal do usuário, permitindo gerenciar tarefas, projetos, áreas, notas, listas e tags.
